STATS 401 · Lab 3

Web Data Acquisition with Python

This project demonstrates a responsible, reproducible workflow for acquiring structured records from the web and presenting them in an interactive table.

Dataset Public book catalogue records Source Books to Scrape Method HTML scraping with Python, requests, and BeautifulSoup Records collected 1,000 books

Dataset Description

The dataset contains all 1,000 books from the 50-page Books to Scrape practice catalogue. Each row has a unique course ID (0001–1000), title, price in British pounds, one-to-five-star catalogue rating, stock status, source page, and direct book URL. The Python script loops through all pages automatically, waits one second between requests, checks HTTP responses, catches request and parsing errors, validates required fields and unique URLs, and saves the result as CSV. Books to Scrape is explicitly provided as a safe scraping sandbox; no login, access control, private information, or human-facing production service is used.
