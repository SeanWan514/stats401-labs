STATS 401 · Lab 3

Web Data Acquisition with Python

This project demonstrates a responsible, reproducible workflow for acquiring structured records from a public API and presenting them in an interactive table.

Dataset Project Gutenberg ebook metadata Source Gutendex API Method REST API acquisition with Python and requests Records collected 1,200 unique books

Dataset Description

This dataset contains 1,200 distinct ebook records from Gutendex, an open JSON API for Project Gutenberg metadata. The Python script followed the API's pagination links and selected the first 1,200 books in download-count order. Every row includes a sequential course ID (0001–1200), the original Gutenberg ID, title, author, language, download count, source URL, and a derived popularity tier. The one-to-five-star popularity tier divides this 1,200-book sample into download-count quintiles; it is not a reader review score. The script used a one-second pause between API pages, bounded retries, request timeouts, HTTP status checking, response validation, duplicate detection, and final dataset validation before saving the CSV. This one-time educational acquisition used public bibliographic metadata, made only the paginated requests needed for the assignment, and collected no personal data.
