STATS 401 · Lab 3

Web Data Acquisition with Python

This project demonstrates a responsible, reproducible workflow for acquiring structured records from the web and presenting them in an interactive table.

Dataset Public book catalogue records Source Books to Scrape Method HTML scraping with Python, requests, and BeautifulSoup Records collected 1,000 books

Dataset Description

The dataset contains every book listed in the site's 50-page practice catalogue. Each record includes its title, price in British pounds, one-to-five-star rating, availability, catalogue page, and source URL. A Python script followed pagination automatically, paused for one second between requests, handled request and parsing failures, validated the final records, and saved them as CSV. The source is designed for scraping practice; the script collected only public catalogue data and did not bypass access controls or collect personal information.
