Cleaning Web Data for Visualization

I built a Python pipeline to clean 1,500 tweets, calculated sentiment with RoBERTa, and prepared the cleaned data for D3; visualization shown below strictly follows the requirements of Lab4. Scroll down for more details!

Dataset Davidson et al. 2017: Automated Hate Speech Detection and the Problem of Offensive Language SourceOriginal GitHub Repository Tweets analyzed 1,500 tweets Sentiment model cardiffnlp/twitter-roberta-base-sentiment-latest

Scope, Methods, and Limitation

Scope. Davidson et al. studied the challenge of distinguishing hate speech from other offensive language. Using the dataset's human annotation categories, this visualization asks: how does RoBERTa-estimated sentiment differ among tweets labeled hate speech, offensive language, or neither?

Dataset. The original corpus contains tweet text and annotation vote counts. I selected a deterministic 1,500-tweet sample, checked missing values and duplicates, converted structured fields to numeric types, validated vote totals and categories, normalized malformed whitespace, and retained 1,500 complete, unique records.

Method. Sentiment was calculated for every cleaned tweet with cardiffnlp/twitter-roberta-base-sentiment-latest. The tidy output retains the predicted label, three class probabilities, sentiment score, and human annotation category. D3 encodes annotation category by x-position and sentiment share by stacked position and color.

Limitation. The probabilities and labels are model-generated estimates, not ground truth; sarcasm, slang, reclaimed language, limited context, and the dataset's sampling and annotation decisions can produce uncertainty or error.

Short Analysis

Overall Analysis

This analysis uses a deterministic 1,500-tweet sample from Davidson et al.'s 2017 dataset. The Python pipeline checked missing and duplicate records, converted annotation counts to numeric values, validated categories and vote totals, normalized whitespace, and prepared separate text for TF-IDF and RoBERTa. Sentiment was estimated for every retained tweet with the required CardiffNLP Twitter RoBERTa model; its score equals the positive probability minus the negative probability. In the 100% stacked bars, x-position identifies the human annotation category, stacked position shows each sentiment's share, and color distinguishes negative, neutral, and positive predictions. Negative predictions dominate hate speech (88.0%) and offensive language (71.3%), whereas neither is balanced across negative (39.3%), neutral (39.7%), and positive (21.0%). As an optional confidence check, the model's highest class probability averaged 75.9%; 309 tweets (20.6%) were below 60% confidence, and 103 (6.9%) had less than a 10-point gap between their two leading probabilities. These cases demonstrate meaningful uncertainty, reinforcing that model predictions are useful summaries rather than ground-truth judgments.
